# 📊 Sales Performance Dashboard – Power BI

## 📌 Project Overview
This project is an interactive Sales Performance Dashboard developed using Microsoft Power BI. It provides insights into sales performance, profitability, customer segments, product categories, and regional sales trends.

The dashboard helps understand business performance through interactive visualizations and data-driven insights.

## 🎯 Key Features
- **Sales Overview:** Total Sales, Total Profit, Quantity and Discount.
- **Yearly Analysis:** Analyze sales performance across different years.
- **Customer Insights:** Understand sales by customer segments.
- **Product Analysis:** Explore product category performance.
- **Regional Analysis:** Compare sales across different regions.
- **Market Analysis:** Analyze market-wise sales performance.
- **Monthly Trends:** Track monthly sales growth.
- **Interactive Filters:** Filter dashboard data using Year Slicer.
